# Pigeon Grabbing

An N64 game about grabbing pigeons.

## Development

This project requires a few things setup:

1. [libdragon](https://github.com/DragonMinded/libdragon/wiki/Installing-libdragon) built locally
2. [tiny3d](https://github.com/HailToDodongo/tiny3d) built locally

I ran into issues with the `GCC MIPS64 toolchain` - but I really just needed to make sure `xcode-select --install` was properly installed and agreed to.
