# Blender Plugin Export Notations

## Base Tags

| base tag | denotes       |
| -------- | ------------- |
| `a_`     | an actor      |
| `e_`     | an entity     |
| `d_`     | a door        |
| `sp_`    | a spawn point |

## Modifier Flags

| modifier | denotes                             |
| -------- | ----------------------------------- |
| \*`sc_`  | mark as an object to skip culling   |
| `s_`     | skip (mark as hidden to start with) |

`*` currently not being used
